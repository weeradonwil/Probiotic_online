คู่มือติดตั้ง Probiotic Shop บนเครื่องใหม่

============================================================
1. โปรแกรมที่ต้องติดตั้ง
============================================================

1) Node.js 24 พร้อม npm หรือ Node.js 22.12 ขึ้นไป
   ใช้รันทั้ง backend และ frontend
   ดาวน์โหลด: https://nodejs.org/en/download

2) Git
   ใช้โคลนโค้ดจาก GitHub

3) MySQL 
   ใช้เก็บข้อมูลบัญชี สินค้า คำสั่งซื้อ และการชำระเงิน
   ใช้ชุด XAMPP ใช้ phpMyAdmin ให้เปิด Apache ด้วย


ตรวจว่าโปรแกรมพร้อมใช้งาน

   node --version
   npm.cmd --version
   git --version

Frontend ใช้ Vue, Vue Router, Vite และ Tailwind CSS
Backend ใช้ Express, mysql2, bcrypt, JWT, Nodemailer และ middleware อื่น
ไม่ต้องติดตั้งแพ็กเกจเหล่านี้ทีละตัว คำสั่ง npm.cmd ci จะติดตั้งให้ครบ

============================================================
2. โคลนโปรเจกต์
============================================================


   git clone https://github.com/weeradonwil/Probiotic_online.git
   cd Probiotic_shop

เปิดโฟลเดอร์นี้ใน VS Code
ภายในต้องมีโฟลเดอร์ backend และ frontend

ไฟล์ .env และ node_modules ไม่ได้มากับการโคลน
แต่ละเครื่องต้องสร้าง .env และติดตั้ง dependencies เอง

============================================================
3. เตรียมฐานข้อมูลก่อนรัน backend
============================================================

1) เปิด MySQL 
2) นำไฟล์ probiotic_shop.sql ไป import ด้วย phpMyAdmin
3) ตรวจว่ามีฐานข้อมูลชื่อ probiotic_shop และตารางของระบบ


============================================================
4. ติดตั้ง backend และสร้างไฟล์ตั้งค่า
============================================================

เปิด terminal 

   cd backend
   npm.cmd ci
   Copy-Item .env.example .env

คำสั่ง Copy-Item ใช้ตอนติดตั้งครั้งแรกที่ยังไม่มี .env
หากมี .env อยู่แล้ว ให้แก้ไฟล์เดิม ไม่คัดลอกแม่แบบทับค่าที่ตั้งไว้

เปิด backend/.env แล้วกำหนดค่าให้ตรงกับเครื่องใหม่:

   PORT=3000
   CORS_ORIGIN=http://localhost:5173

   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_USER=ชื่อผู้ใช้ฐานข้อมูล
   DB_PASSWORD=รหัสผ่านฐานข้อมูล
   DB_NAME=probiotic_shop

   JWT_SECRET=secretที่สร้างบนเครื่องนี้
   JWT_EXPIRES_IN=2h
   FRONTEND_URL=http://localhost:5173

ค่าด้านบนเป็นตัวอย่าง ต้องเปลี่ยนชื่อผู้ใช้ รหัสผ่าน และ secret จริง
ถ้าผู้ใช้ฐานข้อมูลไม่มีรหัสผ่าน ให้เว้น DB_PASSWORD ว่าง

สร้าง JWT secret ด้วยคำสั่ง:

   node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"

คัดลอกผลลัพธ์ไปใส่ JWT_SECRET ใน .env แล้วบันทึกไฟล์
เก็บข้อมูลลับใน .env เท่านั้น ไม่ใส่ใน .env.example หรืออัปโหลดขึ้น Git

============================================================
5. ตั้งค่าการส่งอีเมลรีเซ็ตรหัสผ่าน
============================================================

หากต้องการใช้การรีเซ็ตรหัสผ่านผ่านอีเมล ให้เพิ่มค่าใน backend/.env:

   SMTP_HOST=smtp.gmail.com
   SMTP_PORT=465
   SMTP_USER=อีเมลของร้านที่ใช้ส่ง
   SMTP_PASS=AppPasswordของบัญชีผู้ส่ง

ขั้นตอนสำหรับ Gmail

1) เข้าบัญชี Google ที่จะใช้เป็นผู้ส่ง
2) เปิดการยืนยันแบบ 2 ขั้นตอน
3) สร้าง App Password สำหรับ Probiotic Shop
4) ใส่อีเมลบัญชีนั้นใน SMTP_USER
5) ใส่ App Password ใน SMTP_PASS แบบติดกัน ไม่มีช่องว่าง

หน้า App Passwords: https://myaccount.google.com/apppasswords
คำแนะนำ Google: https://support.google.com/accounts/answer/185833?hl=th

SMTP_USER ต้องเป็นบัญชีเดียวกับที่สร้าง App Password
อีเมลลูกค้าที่รับลิงก์จะดึงจาก accounts.email ในฐานข้อมูล
ไม่ต้องใส่อีเมลลูกค้าใน .env และไม่ใช้รหัสผ่าน Gmail ปกติเป็น SMTP_PASS

หากยังไม่ได้ตั้ง SMTP ส่วนอื่นของเว็บยังใช้งานได้
แต่บริการขอลิงก์รีเซ็ตรหัสผ่านจะยังไม่พร้อม

============================================================
6. อัปเดตโครงสร้างบัญชีและตรวจระบบอีเมล
============================================================

ใน terminal ที่อยู่ใน backend ให้รัน:

   npm.cmd run migrate:password-reset

ต้อง import ฐานข้อมูลและมีตาราง accounts ก่อนรันคำสั่งนี้
สคริปต์จะเพิ่มคอลัมน์ reset token และ token_version ที่ยังขาด
รันซ้ำได้โดยไม่ลบบัญชีเดิม

หากตั้ง SMTP แล้ว ให้ตรวจด้วย:

   npm.cmd run check-mail

คำสั่งนี้ตรวจการเชื่อมต่อและ authentication โดยไม่ส่งอีเมล
ต้องเห็นข้อความว่า SMTP connection and authentication verified

ถ้าพบ EAUTH / SMTP 535 ให้ตรวจว่า SMTP_USER ตรงกับบัญชี
ที่สร้าง App Password และรหัสยังใช้งานได้

============================================================
7. สร้าง Admin หากฐานข้อมูลยังไม่มี
============================================================

กำหนด ADMIN_USERNAME, ADMIN_EMAIL และ ADMIN_FULL_NAME ใน .env
รหัสผ่าน Admin ให้กำหนดชั่วคราวใน terminal แล้วรัน:

   $env:ADMIN_PASSWORD = 'แทนข้อความนี้ด้วยรหัสผ่านของคุณ'
   npm.cmd run create-admin
   Remove-Item Env:ADMIN_PASSWORD

รหัสผ่านต้องมีอย่างน้อย 8 ตัวอักษร มีพิมพ์ใหญ่ พิมพ์เล็ก ตัวเลข
อักขระพิเศษ ไม่มีช่องว่าง และยาวไม่เกิน 72 ไบต์

ถ้ามี username หรือ email นี้ในฐานข้อมูลแล้ว สคริปต์จะไม่สร้างซ้ำ

============================================================
8. เปิด backend
============================================================

ใน terminal หน้าต่างที่ 1 ซึ่งอยู่ใน backend:

   npm.cmd run dev

เปิดตรวจสถานะ:

   http://localhost:3000/api/health

ต้องได้ status: ok และ database: connected
ปล่อย terminal นี้รันไว้ขณะใช้งานเว็บ

เมื่อแก้ .env ให้หยุด backend ด้วย Ctrl+C แล้วรันใหม่
เพื่อโหลดค่าตั้งค่าล่าสุด

============================================================
9. ติดตั้งและเปิด frontend
============================================================

เปิด terminal หน้าต่างที่ 2 โดยเริ่มจากโฟลเดอร์ Probiotic_shop:

   cd frontend
   npm.cmd ci
   npm.cmd run dev

เปิดหน้าเว็บ:

   http://localhost:5173

ปล่อย backend และ frontend รันพร้อมกันคนละ terminal
Vite จะส่งคำขอ /api ไป backend ที่พอร์ต 3000 ขณะพัฒนา
ใช้พอร์ต 5173 สำหรับ frontend ให้ตรงกับค่าที่ตั้งใน .env

============================================================
10. ตรวจว่าติดตั้งสำเร็จ
============================================================

[ ] หน้าเว็บเปิดได้ที่ localhost:5173
[ ] /api/health แจ้งว่าฐานข้อมูลเชื่อมต่อแล้ว
[ ] รายการสินค้าและหมวดหมู่โหลดได้
[ ] สมัครสมาชิกและเข้าสู่ระบบได้
[ ] บัญชี Admin เข้าหน้าจัดการสินค้าได้
[ ] ถ้าตั้ง SMTP: check-mail ผ่าน
[ ] ทดสอบขอลิงก์ด้วยอีเมลสมาชิก รับอีเมล และตั้งรหัสผ่านใหม่ได้

คำสั่งเพิ่มเติม:

   ใน backend:  npm.cmd run test:password-reset
   ใน frontend: npm.cmd run build

ชุดทดสอบรีเซ็ตต้องเชื่อม MySQL และรัน migration แล้ว
ใช้ตารางชั่วคราวแยกจากบัญชีจริง และจำลองการส่งอีเมล

============================================================
11. ข้อควรรู้ก่อน deploy
============================================================

คู่มือนี้เป็นการรันบนเครื่องตัวเอง ขึ้นเว็บจริงต้องตั้งค่าเพิ่มเติม:

- ตั้ง NODE_ENV=production
- เปลี่ยน FRONTEND_URL และ CORS_ORIGIN เป็นโดเมนจริง
- ใช้ HTTPS และเก็บ credentials ใน environment ของ backend
- เตรียมฐานข้อมูลบนเซิร์ฟเวอร์และรัน migration
- ตั้ง /api ให้ส่งไป backend เพราะ Vite dev proxy ไม่ได้ทำงานหลัง build
- ตั้ง fallback ให้เปิด /reset-password และหน้า Vue อื่นโดยตรงได้
- ตรวจ SMTP และทดสอบรับอีเมลจากเซิร์ฟเวอร์จริงอีกครั้ง

ไฟล์อ้างอิงในโปรเจกต์:

   backend/.env.example  แม่แบบค่าตั้งค่า ไม่มีข้อมูลลับจริง
   backend/README.md     รายละเอียดระบบรีเซ็ตรหัสผ่านและ SMTP
   PROJECT_STATUS.md     สถานะงานที่ทำแล้วและยังขาด

============================================================
สรุปการเปิดครั้งถัดไปหลังติดตั้งเสร็จแล้ว
============================================================

1) เปิด MySQL
2) เปิด terminal ใน backend แล้วรัน npm.cmd run dev
3) เปิด terminal อีกหน้าใน frontend แล้วรัน npm.cmd run dev
4) เปิด http://localhost:5173

ไม่ต้องรัน npm.cmd ci, import SQL หรือสร้าง Admin ใหม่ทุกครั้ง
หาก dependencies เปลี่ยนหลังดึงโค้ดใหม่ จึงค่อยติดตั้งแพ็กเกจใหม่
